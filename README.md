# Система учёта животных в приюте

## 1. Описание проекта

Программа предназначена для автоматизации работы приюта животных. Она позволяет вести учёт животных, сотрудников, владельцев и записей о пристройстве.

Проект разработан на языке Python с использованием базы данных SQLite.

## 2. Основные возможности

В системе предусмотрены две роли пользователей:
### Сотрудник приюта

- Вход в систему и регистрация.
- Просмотр списка животных.
- Добавление животных.
- Изменение данных животных.
- Удаление животных.
- Просмотр списка владельцев.
- Просмотр записей о пристройстве.

### Администратор

- Вход в систему.
- Просмотр, добавление, изменение и удаление сотрудников.
- Управление данными о животных.
- Управление данными о владельцах.
- Управление записями о пристройстве.

## 3. Используемые технологии

- **Python** — язык программирования.

- **PlantUML** — создание диаграмм.

## 5. Структура базы данных

Для хранения информации используется база данных SQLite. Она состоит из пяти таблиц:

| Название таблицы | Назначение |
|---|---|
| employees | Хранение информации о сотрудниках |
| animals | Хранение информации о животных |
| adopters | Хранение информации о владельцах |
| adoptions | Хранение записей о пристройстве |
| users | Хранение учётных записей пользователей |

Для связи таблиц используются первичные и внешние ключи. Фамилия, имя и отчество сотрудников и владельцев хранятся в отдельных полях.
