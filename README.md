Система учёта животных в приюте
О проекте
Тема моего проекта — «Система учёта животных в приюте». Такая система нужна для того, чтобы упростить работу с информацией о животных, которые находятся в приюте. С её помощью можно организовать учёт животных и сделать работу с данными более удобной.
Проект рассматривает работу двух пользователей: сотрудника приюта и администратора. У каждого пользователя своя роль при взаимодействии с системой.
В этой лабораторной работе я настраиваю среду разработки, использую Git для сохранения изменений и GitHub для хранения проекта. Также я оформляю документацию с помощью Markdown и подготавливаю диаграмму с использованием PlantUML.
Цель работы
Цель лабораторной работы — научиться оформлять программный проект, хранить его исходные файлы в системе контроля версий и размещать проект в удалённом репозитории GitHub.
Также необходимо освоить основные возможности Markdown для оформления документации и познакомиться с созданием диаграмм в PlantUML.
Пользователи системы
В проекте предусмотрены две роли пользователей.
	●	Сотрудник приюта. Работает с информацией о животных и выполняет задачи, связанные с их учётом.
	●	Администратор. Отвечает за административные задачи и работу с системой в пределах своих прав.
Разделение пользователей на роли позволяет учитывать, что разные люди могут выполнять разные действия в системе.
Основные возможности проекта
Система учёта животных в приюте рассматривается как проект, предназначенный для организации информации о животных и взаимодействия пользователей с ней.
К основным задачам, которые рассматриваются в проекте, относятся:
	●	учёт информации о животных;
	●	работа сотрудников приюта с данными;
	●	организация взаимодействия пользователей с системой.
Подробное поведение системы описывается в диаграмме вариантов использования.
Используемые технологии
В ходе лабораторной работы используются следующие инструменты:
	●	Язык C — для создания простой программы и проверки работы с исходным кодом.
	●	Visual Studio Code — среда для написания и редактирования файлов проекта.
	●	Git — система контроля версий, позволяющая сохранять изменения в проекте.
	●	GitHub — платформа для хранения репозитория и доступа к файлам проекта.
	●	Markdown — язык разметки для оформления файла README.
	●	PlantUML — инструмент для создания диаграмм по текстовому описанию.
Тестовая программа
Для проверки настройки проекта создана простая программа на языке C. Она выводит на экран сообщение Hello, World!.
Эта программа используется для проверки работы с исходным кодом, сохранения изменений с помощью Git и размещения файлов на GitHub. Она не реализует все функции системы учёта животных, а служит примером программы в рамках лабораторной работы.
Диаграмма проекта
Для описания системы используется диаграмма вариантов использования. На ней показаны два участника: сотрудник приюта и администратор.
Диаграмма помогает представить взаимодействие пользователей с системой и показать, какие действия предусмотрены для каждой роли. Исходный файл диаграммы и её изображение будут храниться в папке documents/diagrams/.
Структура проекта
Файлы проекта распределены по папкам в зависимости от их назначения:
	●	src/ — исходный код программы.
	●	documents/ — документация проекта.
	●	documents/diagrams/ — исходные файлы диаграмм и их изображения.
	●	tests/ — папка для тестов программы.
	●	README.md — описание проекта и используемых инструментов.
Такая структура помогает разделить программный код, документацию и тестовые материалы, чтобы файлы было проще находить и редактировать.
Результат работы
В результате лабораторной работы создан проект с программой на языке C и файлом README.md. Настроена работа с Git, создан удалённый репозиторий на GitHub и выполнена отправка файлов в него.
Также подготовлена основа для размещения диаграммы проекта и дальнейшего оформления документации с помощью Markdown и PlantUML.
