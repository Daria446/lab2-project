Система учёта животных в приюте
Система учёта животных в приюте — учебный проект, предназначенный для автоматизации основных процессов работы приюта. Программа позволяет хранить сведения о животных, сотрудниках и будущих владельцах, оформлять записи о пристройстве животных и управлять данными с помощью консольного интерфейса.
Проект разработан на языке Python с использованием базы данных SQLite. При реализации применяются модели данных, репозитории для взаимодействия с базой данных, сервисный слой для обработки бизнес-логики и пользовательский интерфейс.

Возможности системы
В программе предусмотрено два типа пользователей: администратор и сотрудник приюта.
Для сотрудника приюта
	●	Вход в систему под своей учётной записью.
	●	Просмотр и изменение информации о животных.
	●	Добавление новых животных.
	●	Удаление записей о животных.
	●	Просмотр списка будущих владельцев.
	●	Просмотр записей о пристройстве животных.
	●	Выход из учётной записи.
Для администратора
	●	Вход в систему под учётной записью администратора.
	●	Просмотр и управление сведениями о сотрудниках.
	●	Добавление, изменение и удаление записей о сотрудниках.
	●	Просмотр и управление информацией о животных.
	●	Просмотр и управление сведениями о будущих владельцах.
	●	Просмотр и управление записями о пристройстве животных.
	●	Выход из учётной записи.
Для основных объектов реализованы операции CRUD:
	●	Create — создание новой записи.
	●	Read — просмотр существующих записей.
	●	Update — изменение информации.
	●	Delete — удаление записи.

Архитектура проекта
Для организации программы используется разделение на несколько уровней.
       Пользователь
             |
             v
  Пользовательский интерфейс
          main.py
             |
             v
      Сервисный слой
         services
             |
             v
      Слой репозиториев
       repositories
             |
             v
        База данных
          SQLite
Каждый уровень выполняет определённые задачи:
	●	Пользовательский интерфейс отвечает за отображение меню, получение данных от пользователя и вывод результатов.
	●	Сервисный слой содержит бизнес-логику, проверяет корректность данных и существование необходимых записей.
	●	Слой репозиториев выполняет операции с базой данных: добавление, получение, изменение и удаление записей.
	●	База данных хранит информацию, необходимую для работы системы.
Такое разделение упрощает разработку, проверку и дальнейшее расширение программы.
Основные компоненты
Модели (models)
Модели описывают объекты информационной системы. Для их создания используется dataclass.
В проекте предусмотрены следующие модели:
	●	Employee — сотрудник приюта.
	●	Animal — животное.
	●	Adopter — будущий владелец.
	●	Adoption — запись о пристройстве.
	●	User — пользователь системы.
Модели позволяют представить записи базы данных в виде объектов Python.
Репозитории (repositories)
Репозитории отвечают за взаимодействие с базой данных SQLite.
В проекте реализованы:
	●	EmployeeRepository;
	●	AnimalRepository;
	●	AdopterRepository;
	●	AdoptionRepository;
	●	AuthRepository.
Для основных сущностей предусмотрены методы получения всех записей, получения записи по идентификатору, добавления, изменения и удаления.
Файл database.py содержит функцию подключения к базе данных.
Сервисы (services)
Сервисы содержат правила обработки данных и обращаются к репозиториям для выполнения операций.
В проекте реализованы:
	●	EmployeeService;
	●	AnimalService;
	●	AdopterService;
	●	AdoptionService;
	●	AuthService.
Сервисный слой выполняет проверку обязательных полей, корректности возраста животного, уникальности номера телефона, существования записей и соблюдения правил пристройства.
Например, система не позволяет пристроить одно и то же животное повторно или оформить пристройство с указанием несуществующего владельца или сотрудника.
Пользовательский интерфейс
Файл main.py содержит консольный интерфейс программы.
Пользователь может выбрать необходимое действие в меню, ввести данные и получить результат выполнения операции.
В зависимости от роли после авторизации открывается соответствующее меню.
База данных
Для хранения информации используется SQLite.
База данных состоит из пяти таблиц:
|Таблица    |Назначение                    ||-----------|------------------------------||`employees`|Сведения о сотрудниках приюта ||`animals`  |Информация о животных         ||`adopters` |Сведения о будущих владельцах ||`adoptions`|Записи о пристройстве животных||`users`    |Учётные записи пользователей  |
Для идентификации записей используются первичные ключи PRIMARY KEY. Связи между таблицами организованы с помощью внешних ключей FOREIGN KEY.
В таблицах используются ограничения, например NOT NULL и UNIQUE, которые помогают поддерживать целостность данных.
Файлы базы данных
	●	database/schema.sql — SQL-команды для создания таблиц.
	●	database/shelter.db — основная база данных SQLite.
	●	database/shelter_backup.db — резервная копия базы данных.
Авторизация и регистрация
В программе реализована система регистрации и авторизации пользователей.
При запуске пользователь может выбрать вход в систему, регистрацию или выход из программы.
Для регистрации необходимо указать логин и пароль. Новые пользователи получают роль сотрудника приюта. Учётная запись администратора создаётся отдельно.
После успешной авторизации программа определяет роль пользователя и открывает соответствующее меню.
Для хранения учётных записей используется таблица users, содержащая идентификатор пользователя, логин, пароль и роль.

Установка и запуск
1. Получение проекта
Репозиторий проекта размещён на GitHub:
Открыть репозиторий lab2-project
Для получения проекта выполните команды:
git clone https://github.com/Daria446/lab2-project.git
cd lab2-project
2. Проверка Python
Для проверки установленной версии Python выполните команду:
python3 --version
3. Запуск программы
Из корневого каталога проекта выполните:
python3 src/main.py
При запуске программа подключается к базе данных. Если база данных отсутствует, она создаётся на основе SQL-схемы.
После запуска открывается начальное меню программы, в котором доступны вход, регистрация и выход.
