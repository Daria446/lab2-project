# Лабораторная работа № 2

## Описание проекта

Проект создан для изучения Git, GitHub, Markdown и PlantUML.

## Программа

Программа написана на языке C и выводит сообщение Hello, World!

## Используемые технологии

- C
- Git
- GitHub
- Markdown
- PlantUML

## Запуск программы

Для запуска необходимо скомпилировать файл main.c и выполнить полученную программу.
